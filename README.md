## Digital Modulation in VHDL

This project was developed for the Reconfigurable Systems and Data Communication subjects at CEFSA (Centro Educacional Fundação Salvador Arena) in 2026 for the EC7 class.

The objective is to implement and simulate two unipolar digital modulation systems in VHDL using Vivado:

- Unipolar NRZ-L
- Unipolar NRZ-I
